The minimum received becomes the swap's amountOutMinimum. If the pool moves beyond it before your transaction lands, the swap reverts instead of filling at a worse price.

Approvals & swap — up to three wallet confirmations

The Universal Router pulls your input token through Permit2, so a swap takes up to three wallet confirmations. Each approval is for the exact swap amount only — never unlimited.

  1. Approve USDC → Permit2 — one ERC-20 approval letting Permit2 move the input token.
  2. Permit2 → Universal Router — lets the router spend that allowance for this swap (1-year expiry, exact amount).
  3. Swap on the Universal Router — V4_SWAP · SWAP_EXACT_IN_SINGLE + SETTLE_ALL + TAKE_ALL, 30-minute deadline.

Once the wallet is connected and an amount is entered, the primary "Swap" button is enabled and a transaction log records each step.

Why wallet apps can't quote this pool

The pool's custom hook takes a 3% fee from the swap's output token — $MUSE on a buy, USDC on a sell — paid to the agent wallet 0x0A1D2730f4Ae736Bac3D772FaB8607BFd7F650C4. That hook makes Uniswap's official V4Quoter revert, and every aggregator behind Bitget Wallet, OKX Web3, and MetaMask Swap depends on a quoter, so they all answer "No quote available".

The interactive page never calls the quoter. It reads the pool's sqrtPriceX96, tick, and liquidity straight from the PoolManager, runs the Uniswap V4 exact-input math itself (single position range, ticks 304080–308520), then builds the same Universal Router calldata that completed the pool's first live swap on 2026-11-07. Quotes are estimates from the block shown above — if the price leaves the position's range, liquidity runs out and large swaps can only fill partly up to the range edge.
