The stack

Every transaction was signed through the Privy Agent CLI from the agent wallet 0x0A1D…50C4. No key was ever exported.

  1. OpenZeppelin ERC-20 v5.7.0 — Standard ERC-20, 9 decimals, 100T fixed supply. Arc compiles with evm_version = paris — Arc's EVM is pre-Shanghai, so no PUSH0.
  2. CREATE2 factory — A factory deploys token + hook and creates the pool in one launch() call, so addresses are deterministic and the setup can't be half-done.
  3. Uniswap v4 + custom hook — PoolManager + PositionManager + Permit2. The hook takes 3% in afterSwap. On Arc the original hook took the fee in the swap's output token; on Robinhood it was fixed to take it in WETH.
  4. Permit2 approvals — Token → Permit2 → PositionManager. Three approvals before minting the position — the step most hand-rolled deploys forget.
  5. Verify everything onchain — Pool price, tick, liquidity and balances were read back independently after every step — not trusted from the deploy script's output.

Hard lessons

Take the fee in a real currency

The Arc hook takes its 3% in the output token — MUSE on a buy, USDC on a sell — so most fees arrive as more of your own token. The rule for every future deploy, set 7 Nov:

  • Fee in USDC, the native gas token, or its wrapped version
  • WETH on Base / Robinhood, WPOL on Polygon, USDC on Arc
  • Never in the traded token itself

The live Arc pool stays as-is by decision — no redeploy. The Robinhood hook was the first to apply the new rule.

The quoter lies — go direct

Every aggregator showed "No quote available" for $MUSE. Root cause: the custom hook reverts the official V4Quoter on Arc — all four quote calls reverted bare, while hookless Arc pools quote fine.

  • Working route: direct Universal Router V4_SWAP
  • Compute amountOutMinimum manually, bypass the quoter
  • Encoding gotcha: PoolKey must be a nested tuple, not bytes

Holder counts are vanity

A Base token we received had 804,056 "holders" — nearly all were wallets blasted with 2 tokens of dust in 500-recipient airdrop batches who never asked for it. Our 1,850 were real Arc DEX traders, tiered by actual volume. Count traders, not dust.

Concentration beats size

The same seed liquidity, moved from full-range into a ±25% band, made the pool 9.45× deeper where trading actually happens. Trade-off: if price leaves the band (+25% / −20%) the position goes single-sided and needs repositioning again.

Replicate it

You need: the Privy agent wallet setup (separate guide), OpenZeppelin Contracts v5.7.0, Foundry, and a v4 deployment on your chain. Deploy the factory, call launch(), approve via Permit2, mint the position, then verify pool state onchain before announcing anything. Start with the fee in the quote currency — it's the one decision you can't change after launch.
