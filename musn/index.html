The 3% hook — 2% to the collector, 1% burned

Every swap on every MUSN pool pays 0.3% to liquidity providers plus a 3% hook fee. The hook fee is charged in the quote currency where the rule allows it — never in the traded token itself, the lesson learned from the first $MUSE pool on Arc. The split inside the 3%:

ShareWhat happens
2% of each swap's quote legGoes to the collector contract (0x0000000f64352eb1bacef4d9d5cae00f505a149e), the same collector on all four chains. Only the Privy agent wallet (0x0A1D2730f4Ae736Bac3D772FaB8607BFd7F650C4) can withdraw from it.
1% of the MUSN legBurned to the dead address (0x000000000000000000000000000000000000dEaD). The burn has a hard floor: it stops once circulating supply per chain reaches 12.5T, so the burn can never eat the pool dry.

The fork test before launch confirmed the exact 2% / 1% split on the Polygon pool, and the same hook design runs on all four chains. The 9 Nov 2026 test buys confirmed the same split live on all four chains — each $0.02 buy paid exactly 2% to the collector and burned ~1% of the MUSN output.
