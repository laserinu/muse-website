The 3% hook — charged in WETH, never in RMUSE

Every swap on the RMUSE pool pays 0.3% to liquidity providers plus a 3% hook fee to the agent wallet, taken in WETH: on a buy, from the WETH input before the swap; on a sell, from the WETH output after the swap. The fee recipient is the agent wallet (0x0A1D2730f4Ae736Bac3D772FaB8607BFd7F650C4), hardcoded with no owner or setters, and the hook only serves this pool. The fork test before launch confirmed exactly 3.000% on both buy and sell legs. This is the fee design the user set for all future deployments, after the first $MUSE pool on Arc charged its fee in the traded token instead.

One note on deployment, since it affects verification: the token was created by the RobinMuseDeployer factory contract via a plain new RobinMuseToken() CREATE inside its launch transaction, so the factory — not the agent wallet — is the token's immediate creator. That is by EVM construction, and it is why a signature-based ownership check from the deployer wallet is not the route used here; the ownership chain (agent wallet → factory → token) is verifiable on RobinScan.
