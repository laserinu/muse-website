How we DYOR — every time

The standing rule since Nov 6: research and verify before recommending or claiming. If it fails a check, it doesn't get funded — no exceptions for hype.

  1. Verify the source. Official docs and onchain contracts first. Directory labels and marketing pages don't count.
  2. Check the money. Real fees, real gas, real custody. Who holds the keys? Who can pause, mint, or drain?
  3. Hunt red flags. Placeholder addresses, bundled snipes, fake holder counts, unlimited approvals.
  4. Test small, prove it. A claim isn't proven until a live test or onchain read confirms it. Then we label it PROVEN.
  5. Save everything. Every lesson goes to the full report + tools-and-sites log + memory. Nothing learned gets dropped.

Proven onchain — Nov 7, 08:06 WIB

The lesson that changed how we read holder counts: the Base CLAUDE blast

One Base transaction sent 2 CLAUDE to 500 recipients (1,000 total) for about $0.10 — 7,873,399 gas, ~15,747 per recipient. The contract is a minimal owner-only airdrop(address[], uint256[]) that loops transferFrom(owner, recipient, amount). Tokens come from the owner's wallet via allowance, not from the contract. The same owner ran 25+ batches at that size.

Our agent wallet received 2 CLAUDE in one batch. The token shows 804,056 holders — and the conclusion we saved is blunt: those holders are inflated by mass airdrop spam to wallets that never asked for it. Most hold exactly 2 tokens of dust and never traded.

Holder count is a vanity metric. Contrast: our $MUSE airdrop went to 1,850 real Arc traders who actually swap. For a future Base airdrop, 500-recipient batches are proven — about $0.37 for 1,850 recipients vs 1.28 USDC on Arc. Same pattern as our own Disperse contract.

Batch size 500 proven · Cost ~$0.10 / batch · CLAUDE 0xA8DEF24B… · 18 dec · 1B supply.

Top 5 to wire up first

Privy agent wallet integrations

  1. KyberSwap — keyless swaps, no fee, covers Base / Robinhood / Arc. Proven live Nov 6.
  2. Relay — proven bridges (our 3 live bridges ran through it)
  3. x402 — pay-per-call, USDC on Base (EIP-712 typed-data payment)
  4. LI.FI — bridge + swap, no key needed
  5. Jupiter — Solana swaps

Hard limits found: Coinbase AgentKit's PrivyWalletProvider works for Privy server wallets, not the CLI session. Privy's MCP server is docs-only, not signing. ElizaOS default plugins need a private key — incompatible. Odos shut permanently on Jul 30, 2026 — do not use. x402 and MPP payments are EIP-712 typed data and are not covered by eth_sendTransaction policies.

WalletConnect — who it's actually for

Open protocol v2 under Reown: wallet-to-dApp via wc: URI + relay; the key never leaves the wallet and the user approves every signature. Works for any EVM chain via eip155 — Robinhood 4663 and Arc 5042 included.

Key point: the Privy agent wallet cannot use WalletConnect. It's for the user's own self-custody wallets. Muse reaches the agent wallet via calldata + Privy CLI instead.

Measured — Nov 7, 04:54 WIB

The gas floor nobody can beat

Verdict: "all 1,850 + no claim + very low gas" is mutually impossible. Measured batched multisend: 50,799,444 gas total = 1.0160 USDC at 20 gwei. Hard floor ~0.83 USDC, because every fresh holder needs a 20,000-gas SSTORE.

Arc's block gas limit is 30M (so ≥2 chunks), and Arc baseFee is fixed at exactly 20 gwei — verified over 1,000 blocks. The airdrop then executed for 1.284419 USDC total across 10 chunks, all 1,850 balances verified, 0 mismatches.
